# Как запустить Dota 2 Tracker

## Что понадобится

1. **Flutter SDK** версии 3.47 или новее.
2. **Android Studio** (или VS Code с расширением Flutter).
3. **Android SDK** и эмулятор Android либо телефон с включённой отладкой по USB.
4. Интернет — приложение берёт данные из OpenDota API.

Проверить окружение:

```bash
flutter doctor
```

Все пункты для Android должны быть с галочкой.

## Запуск за 5 шагов

### 1. Открыть проект

Открой папку `flutter_dota_tracker` в Android Studio или VS Code.

### 2. Установить зависимости

В терминале в папке проекта:

```bash
flutter pub get
```

### 3. Запустить эмулятор

В Android Studio: **Device Manager → Pixel_API_36 → Start**.

Или в терминале:

```bash
flutter emulators
flutter emulators --launch Pixel_API_36
```

### 4. Запустить приложение

```bash
flutter run
```

Первый запуск занимает несколько минут: Gradle скачивает зависимости.

### 5. Готово

Откроется экран поиска. Введите ник, например `Dendi`, или Steam ID, например `86745912`.

## Запуск двойным кликом

В корне проекта есть `ЗАПУСК.bat` для Windows. Он делает `flutter pub get` и `flutter run`.
Эмулятор или телефон должны быть уже включены.

## Готовый APK

Собранный release-файл лежит здесь:

```text
build/app/outputs/flutter-apk/app-release.apk
```

Установка на подключённый телефон:

```bash
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

Либо просто перекиньте `app-release.apk` на телефон и откройте файл.

## Если что-то не работает

### `No devices found`

Эмулятор не запущен или телефон не подключён. Проверьте:

```bash
flutter devices
```

### `Waiting for another flutter command to release the startup lock`

Закройте лишние окна терминала и повторите команду. Если не помогло — удалите файл `bin/cache/lockfile` в папке Flutter SDK.

### Ошибка Gradle или Java

Убедитесь, что в Android Studio установлен JDK (обычно `jbr`). В VS Code проверьте путь:

```bash
flutter config --jdk-dir "C:\Program Files\Android\Android Studio\jbr"
```

### Приложение запустилось, но данных нет

OpenDota иногда отвечает медленно или включает лимит запросов. Подождите минуту и потяните список вниз для обновления. Проверьте интернет.

### `Vite manifest not found`

Это ошибка из другого проекта. Здесь Vite не используется.

## Структура проекта

```text
lib/
  core/           настройки, сеть, тема, вспомогательные функции
  data/           DTO, OpenDota API, реализации репозиториев
  domain/         сущности и интерфейсы репозиториев
  l10n/           ARB-файлы и сгенерированные переводы
  presentation/   BLoC, экраны и виджеты
    bloc/         search, profile, meta
    cubit/        likes, locale
    screens/      экраны приложения
    widgets/      карточки и общие виджеты
assets/
  icon/           иконка приложения
  images/         логотип на главном экране
test/             модульные тесты
```

## Где искать лабораторные

| Лаба | Файл |
|---|---|
| 1. AppBar с ФИО и группой | `lib/presentation/screens/home_shell.dart` |
| 2. Основы Dart | `lib/presentation/screens/dart_basics_screen.dart` |
| 3. Карточки | `lib/presentation/widgets/hero_card.dart` |
| 4. Лайк и детали | `lib/presentation/widgets/like_button.dart`, `lib/presentation/screens/hero_detail_screen.dart` |
| 5. API, DTO, репозитории | `lib/data/`, `lib/domain/` |
| 6. BLoC, debounce, обновление | `lib/presentation/bloc/` |
| 7. Иконка, локализация, SharedPreferences | `assets/icon/`, `lib/l10n/`, `lib/data/repositories/likes_repository_impl.dart` |
